# 展覽版左頁日記紙感 UI 規範

最後更新：2026-08-26

狀態：展覽版 canonical 視覺規範

基準頁：黃金獵犬／直太郎不完整日記拼圖

這份文件定義展覽版左半邊日記的視覺語彙、版面座標、紙頁素材結構、文字格與按鈕行為。後續若要把同一風格套到其他展覽日記，應先複用這套紙張骨架，再替換內容；不要重新用 CSS 模擬另一套紙邊。

流程與狀態順序另見 [EXHIBITION_DIARY_REVEAL_UNITY_SPEC.md](./EXHIBITION_DIARY_REVEAL_UNITY_SPEC.md)。本文件聚焦 UI 與素材運用。

## 一句話風格定義

像一本只露出左半頁、邊緣有自然毛邊的實體日記：紙張本身乾淨、內容易讀，質感主要來自三層錯位紙頁、細微紙邊、克制陰影與翻頁關係，而不是滿版噪點或厚重仿舊濾鏡。

## 核心視覺原則

1. **介面背景與紙張必須分層。** 點點圖案屬於日記本後方的介面背景，不可印在白色紙頁上。
2. **紙感來自輪廓與堆疊。** 白色正文頁保持乾淨；毛邊、色差、錯位和極淡陰影負責表現紙張厚度。
3. **這是日記的左半頁。** 右側紙張延伸出遊戲舞台並被裁切，不顯示右頁邊縫，也不畫右側裝訂線。
4. **自然感必須克制。** 紙邊要有不規則，但不能像鋸齒、波浪框或平均週期的裝飾線。
5. **內容的可見留白優先。** 紙張盒模型可延伸出畫面；圖片、文字與按鈕的對齊要以玩家實際看得到的紙面為準。
6. **未完成狀態不出現假按鈕。** 不顯示灰色的「拼圖尚未完成」或「日記正在復原」按鈕；完成演出落定後才顯示「繼續」。

## 基準尺寸與層級

目前檢查基準為 `428 × 852` viewport，中央遊戲舞台寬 `393px`。

### 紙張外框

`ExhibitionIncompleteBaiEntry1DiaryPuzzle` 的紙張容器：

| 屬性 | 數值 | 用意 |
| --- | ---: | --- |
| `left` | `27px` | 留出左側三層紙頁與介面背景 |
| `right` | `-18px` | 讓左頁向右延伸出舞台，消除右邊縫 |
| `top` | `72px` | 實測紙張上緣約在畫面 `60px`，位於選單下方 |
| `bottom` | `22px` | 保留底部紙邊與背景 |

在基準 viewport 中：

- 選單按鈕下緣約 `54px`。
- 紙張上緣約 `60px`，兩者相隔約 `6px`。
- 紙張可見高度約 `758px`。
- 紙張底部位置維持約 `818px`。

`EXHIBITION_DIARY_PAPER_FRAME_TOP` 是紙張本體與翻頁遮影共用的唯一垂直基準。若移動紙張，翻頁層也必須同步使用這個常數，避免剛進頁面時出現兩張不同高度的紙。

## 「可見紙面」留白換算

這是本風格最重要的版面技巧。

紙張右側有 `18px` 延伸到舞台外，因此 CSS 中相同的 `left`／`right` 數值，不會形成相同的可見留白。

換算公式：

```text
CSS right = 想要的可見右留白 + 紙張向右延伸量
          = visible inset + 18px
```

### 主內容

| 方向 | CSS 數值 | 實際可見留白 |
| --- | ---: | ---: |
| 左 | `14px` | `14px` |
| 右 | `32px` | `32 - 18 = 14px` |

因此主內容必須使用：

```tsx
left="14px"
right="32px"
```

不能寫成 `left="14px" right="14px"`。那會把畫面外的 `18px` 也算進內容寬度，造成圖片在玩家眼中貼住右邊。

### 完成按鈕

| 方向 | CSS 數值 | 實際可見留白 |
| --- | ---: | ---: |
| 左 | `24px` | `24px` |
| 右 | `42px` | `42 - 18 = 24px` |

完成按鈕必須使用 `left="24px" right="42px"`，不可沿用一般置中卡片常見的左右相同數值。

## 垂直排版

### 日期列

- 相對紙張上緣：`top="31px"`。
- 字體：`Noto Sans TC` 優先，`17px / 400`。
- 字距：`0.1em`。
- 日期、天氣、太陽圖示水平置中，項目間距 `11px`。
- 太陽圖示為 `19 × 19px`。

### 拼圖內容

- 內容容器：`top="70px"`。
- 使用 `alignItems="flex-start"`，不可用垂直置中，否則圖片會被大片空白推離日期。
- 基準畫面中日期列下緣到圖片上緣約 `20px`。
- 圖片和文字格由 `MetroCluePuzzleControl` 以 `12px` gap 串接。

### 完成按鈕

- 高度：`42px`。
- 底部：`31px`。
- 圓角：`5px`。
- 文字：`16px / 700`，字距 `0.08em`。
- 顏色：背景 `#806248`，文字白色。
- 按下時只做 `translateY(2px)`，避免彈性過強破壞紙本感。

## 三層紙頁結構

### 為什麼使用三切片 SVG

紙頁高度會隨裝置與內容改變，因此每一張紙拆成：

```text
top：固定上緣與上角
repeat：可沿 Y 軸重複的中段紙邊
bottom：固定下緣與下角
```

`ExhibitionDiaryPaperFrameAssetLayer` 的疊放順序是：

1. 先鋪中段 `repeat`，範圍為 `top: 10px; bottom: 10px`。
2. 上方覆蓋 `top`。
3. 下方覆蓋 `bottom`。

上下切片會遮住中段接縫，因此能保留自然角落，同時讓頁高保持彈性。

### 前頁與背頁

前頁使用乾淨白紙：

- `card_top.svg`
- `card_repeat.svg`
- `card_bottom.svg`

背後三頁各自擁有獨立素材，不能共用同一張紙只改透明度：

- `left-page-back-1-top/repeat/bottom.svg`
- `left-page-back-2-top/repeat/bottom.svg`
- `left-page-back-3-top/repeat/bottom.svg`

三張背頁的基準錯位：

| 層 | 位移 | 透明度 | 紙色 |
| --- | --- | ---: | --- |
| back-1 | `(-3px, 3px)` | `1` | `#F8F4EC` |
| back-2 | `(-7px, 7px)` | `0.98` | `#F3EEE5` |
| back-3 | `(-10px, 10px)` | `0.96` | `#ECE5DA` |

越後方的紙略深、略往左下移。色差要能辨識，但不應變成三條高對比色帶。

### 中段紙邊技巧

只有上下錯位、但中段維持直線，會讓三頁看起來像三條平行邊框。中段 `repeat.svg` 必須具備：

- 每一層不同的低頻左右游移。
- 沿高度改變露出量，不固定保持同一寬度。
- 曲線起伏不使用完全相同的週期。
- 外側使用極淡棕灰描邊，內側增加極淡白色受光線。
- 受光線約向紙內偏移 `1.05–1.15px`。
- 使用 `vector-effect="non-scaling-stroke"`，避免縮放後描邊忽粗忽細。

中段 SVG 的 `viewBox` 為 `496 × 761`。首尾的紙邊 X 座標應接近或相同，確保 `repeat-y` 接縫不跳動。

不要用下列做法：

- 每隔固定距離重複相同鋸齒。
- 起伏超過數個畫面像素，形成刻意波浪。
- 用高對比陰影勾出每一層。
- 在三張背頁套用同一條 path。

## 文字格規範

黃金獵犬展覽版在拼圖前後使用同一批 `62` 個字元，不可為了排版縮短未完成文字。

| 項目 | 未完成 | 完成 |
| --- | ---: | ---: |
| 字格尺寸 | `20px` | `20px` |
| 字格間距 | `1px` | `1px` |
| 欄數 | `16` | `16` |
| 列數 | `5` | `4` |
| 網格寬 | `335px` | `335px` |
| 邊框 | 無 | 無 |

未完成時使用五列散落格位，列內字數分布為 `12 / 13 / 12 / 13 / 12`；完成後依閱讀順序排成 `16 / 16 / 16 / 14`。

技巧：

- 先固定字元總數，再決定列數與欄數。
- 散落只改 `scatterIndex`，不要刪字、複製字或替換正文。
- 字格邊框在展覽版關閉，靠淡底色區分；避免 62 個框線造成視覺噪音。
- `335px` 網格置中在 `338px` 內容寬中，左右僅留下約 `1.5px`，形成緊湊但仍清楚的閱讀面。

## 翻頁與三層紙頁的關係

- 三張背頁放在 stationary stack，不參與旋轉。
- 只有白色前頁執行 `rotateY` 翻頁。
- 翻頁背面仍使用同一套紙張 frame asset，避免翻到一半露出矩形白盒。
- 陰影層與紙張層共用 `EXHIBITION_DIARY_PAPER_FRAME_TOP`、`left: 27px`、`right: -18px`、`bottom: 22px`。
- 翻頁期間內容不可點擊；教學 modal 關閉後才恢復拼圖操作。

若把三張背頁放進旋轉容器，進場時會看起來像整疊紙一起翻動，破壞「翻一張、下面還有幾頁」的感覺。

## 狀態與按鈕規則

```text
puzzle：沒有繼續按鈕
restoring：沒有繼續按鈕
restored：顯示繼續按鈕
```

實作上只在 `canContinue = solved && isRestorationComplete` 時 render 按鈕；不要先 render disabled button 再用灰色表示不可按。

黃金獵犬的完成節奏：

1. 四片拼圖順序正確。
2. 粗糙稿恢復上色。
3. 小白淡入。
4. 約 `2.26s` 後 restoration complete。
5. 才顯示「繼續」。

這能讓玩家先看完日記修復，再決定前進，不會被底部按鈕提早吸走注意力。

## 篇章目錄套用

展覽版青蛙殘篇入口的交換日記目錄沿用同一套紙張骨架，但它是「目錄頁」而不是「正文頁」：

- 保留點點介面背景、左半頁、三層背頁與右側無縫裁切。
- 不顯示日期列，也不播放正文的圖片修復演出。
- 目錄卡片相對可見紙面左右各留 `14px`。
- 展覽目錄卡統一使用正式日記插圖的 `967:684` 比例，不再使用固定 `162px` 高的寬幅裁切。
- 第一張卡片距紙張上緣 `18px`。
- 返回按鈕使用 `42px` 高，並相對可見紙面左右各留 `24px`。
- 卡片的解鎖、NEW、指標與點擊流程維持原本邏輯；紙張樣式只負責外層容器。
- 已完成篇章要在目錄卡直接顯示該篇目前資料綁定的正式完成圖，不可另取 `public/images/diary` 內的舊版封面；第一篇直接使用 `card.imagePath`，目前對應 `BAI_ENTRY_1_RESTORED_IMAGE_PATH`。
- 完成卡以封面圖本身傳達篇章，不疊加「已完成」、篇章名稱或小日獸名稱等文字。
- 鎖定卡使用由 Figma `12429:762` 匯出的完整封面素材 `diary-lock-cover.png`，不要另外組合純色底、emoji 或文字。
- 揭露卡使用由 Figma `12429:766` 匯出的透明遮罩 `diary-reveal-cover.png`；它必須覆蓋在日記插圖上，不可改用 `diary-lock-cover.png` 或 CSS 多邊形模擬。
- 揭露卡只用圖像傳達狀態，不疊加「殘缺篇章」、篇章名稱或「只浮現第一格」等說明文字。
- 青蛙正式日記圖完成前，第二篇揭露卡暫時以 `BAI_ENTRY_2_CATALOG_REVEAL_PLACEHOLDER_IMAGE_PATH` 指向黃金獵犬完成日記圖；替換正式圖時只改這個常數。
- 未完成與鎖定篇章不得因相鄰卡片完成而提前露出正式小日獸素材；揭露圖只存在於該篇的殘缺卡內。
- 進入「搬家」後仍交回原本的青蛙殘篇流程，不把目錄卡內容誤當成日記正文。

目前由 `usePaperFrameTrialAssets` 控制這個展覽目錄變體，並在 `frog-diary-fragment / catalog` 入口啟用；正式版目錄不受影響。

## 青蛙前置紙膠帶互動頁

青蛙日記特有的紙膠帶／書籤互動，是「同一張日記紙上的互動內容」，不可在日記紙裡再畫一張白色互動頁：

- 外層沿用黃金獵犬的點點介面背景、三層錯位背頁與 `front` 三切片紙張素材。
- 紙張位置沿用 `left: 27px`、`right: -18px`、`top: 72px`、`bottom: 22px`。
- 這個前置頁不顯示星期、天氣、太陽，也不顯示紙膠帶畫布原有的 `03 / 14` 日期記號。
- 不顯示返回按鈕；三張正確紙膠帶完成後，才顯示原本的「翻開日記」。
- 紙膠帶互動 root 直接放在紙面內容區，使用透明背景、`border: 0`、`box-shadow: none`。
- 內容區相對紙張為 `left: 14px`、`right: 32px`、`top: 14px`、`bottom: 20px`，保留左側紙邊與右側無縫裁切的視覺平衡。
- 點陣與橫線可以作為紙面上的淡紋理，但不得附帶第二層白底、圓角、棕色外框或第二組書頁陰影。
- 紙膠帶位置、書籤三個膠痕、拖放判定與完成條件維持原本互動資料，不因換紙張而重排規則。

## 展覽版青蛙日記全階段

前置紙膠帶頁、三篇上段拼圖、拍照後揭露、完整還原與下一篇殘頁，全部視為同一張 `ActivePaper` 上的內容狀態，而不是各自擁有一張內層日記紙：

- 所有階段共用點點介面背景、三層錯位背頁與黃金獵犬的 `front` 三切片紙張素材。
- 所有階段都不顯示星期、天氣、太陽或返回按鈕；流程出口只由當前互動完成後的「繼續」控制。
- 拼圖、揭露與還原元件的 root 必須是透明內容層：`background: transparent`、`border: 0`、`box-shadow: none`，並填滿紙面內容區。
- 不得在 `ActivePaper` 裡重畫條紋背景、棕色外框、圓角頁框或第二組紙張陰影；畫面中可互動的紙永遠只有一張。
- 「???」與「搬家」改成直接印在紙上的頁面標題，使用棕色／青綠文字；不得再以滿版棕色色帶假裝另一張頁面的 header。
- 互動圖片、文字格、地點書籤與完成按鈕保留原有資料和狀態機，只調整它們在紙面內容區內的間距。
- 拍照後仍維持圖片缺片補回、下段青綠文字浮出、標題解析、文字沉回一般日記色，最後才顯示「繼續」的順序。
- 換頁演出只旋轉最前方 `ActivePaper`；三層背頁維持靜止，不因不同青蛙狀態疊出額外紙邊。

### 青蛙頁驗收

- [ ] 任一青蛙日記狀態都只看到一張前頁與三張裝飾背頁。
- [ ] 畫面沒有星期、天氣、太陽、`03 / 14` 或「返回」。
- [ ] 紙面內沒有第二層條紋底、棕框、圓角或頁影。
- [ ] 標題是紙面文字，不是滿寬色帶。
- [ ] 未完成時沒有「繼續」；完成條件達成後才出現。
- [ ] 拼圖答案、地點書籤、上下段文字與線索 overlay 的觸發順序沒有改變。

## 新頁套用流程

1. 先複用整個紙張外框、三層背頁、日期列與翻頁 transition。
2. 確認新頁仍是左半頁；若不是，不可直接沿用 `right: -18px`。
3. 替換插圖時準備相同裁切與比例的未完成／中間／完成素材。
4. 依正文總字數重算網格，但保留 `20px` 字格與 `1px` 間距作為第一選擇。
5. 內容留白用可見紙面公式換算，不直接照抄左右相同值。
6. 只在全部揭露完成後 render 行動按鈕。
7. 同時檢查靜止畫面與翻頁中途；兩者的紙張座標必須相同。

## 驗收清單

### 靜止畫面

- [ ] 選單按鈕沒有壓住紙張，兩者約留 `6px`。
- [ ] 右側沒有紙頁邊縫。
- [ ] 圖片相對可見紙面左右各 `14px`。
- [ ] 完成按鈕相對可見紙面左右各 `24px`。
- [ ] 日期下緣到圖片約 `20px`。
- [ ] 三張背頁在上、中、下都可辨識，但沒有高對比色帶。
- [ ] 中段紙邊不是三條平行直線。
- [ ] 點點背景只存在紙張後方。

### 拼圖與揭露

- [ ] 未完成與完成文字都是 `62` 字。
- [ ] 未完成文字分布為五列，完成後為四列。
- [ ] 字格為 `20px`、間距 `1px`、無 border。
- [ ] 未完成及 restoring 階段沒有底部按鈕。
- [ ] 完成後「繼續」高度為 `42px`。
- [ ] 完成順序仍是粗糙稿 → 上色 → 小白淡入 → 繼續。

### 翻頁

- [ ] 背後三張紙保持靜止。
- [ ] 只有前頁旋轉。
- [ ] 翻頁紙、陰影與靜止紙張的上緣一致。
- [ ] 翻頁背面沒有矩形白邊或右側縫隙。

## 常見錯誤

| 錯誤 | 原因 | 修正 |
| --- | --- | --- |
| 圖片右側貼邊 | 把畫面外 `18px` 紙張算進內容留白 | `right = visible inset + 18px` |
| 三層紙中段像直條 | 三張 repeat edge 太直或共用相同 path | 為每層畫不同的低頻曲線與受光線 |
| 進場時看見四、五張紙 | stationary stack 又跟著前頁旋轉 | 背頁移出翻頁 transform 容器 |
| 翻頁陰影停在舊高度 | 紙張與 transition 使用不同 top | 共用 `EXHIBITION_DIARY_PAPER_FRAME_TOP` |
| 紙感太髒 | 把噪點、灰階與重陰影疊在正文上 | 保持白頁乾淨，把質感放在邊緣與層次 |
| 未完成頁底部有灰按鈕 | 預先 render disabled action | 僅在 `canContinue` 時 render |
| 完成後字數改變 | 未完成文字使用另一份縮短內容 | 拼圖前後共用同一批 token |
