# 拍照精準度、星級與結果演出

更新日期：2026-09-11

本文件記錄這次拍照調整的最終規格。主要實作為
`src/components/game/events/EventPhotoCaptureLayer.tsx`；規則與時間軸位於
`src/lib/game/photoRating.ts`。

## 玩家流程

1. 按下快門，保留既有快門音效、閃白、拍立得顯影與照片掃光。
2. 拍立得下方顯示「拍攝精準度」，數字由 0 跑至實際結果。
3. 有取得星級時，在同一位置將精準度替換成三顆暗星，再由左至右逐顆漸亮；每顆亮起時同步播放對應音效。
4. 最後一顆完成漸亮並停留後，才顯示收下／重拍操作。
5. 使用免費重拍時，第二張也完整播放跑分與亮星，完成後再進入兩張照片的選片畫面。

「取景完成」文字已移除。免費重拍提示位於畫面下方、操作按鈕上方，不放在拍立得內。
未達過關條件時，保留精準度結果、不顯示星星；門檻說明也放在重拍按鈕上方。

## 拍立得排版

| 項目 | 規格 |
| --- | --- |
| 卡片 | 236 × 286 px、白底、7 px 圓角 |
| 照片 | 192 × 192 px，水平置中，距卡片頂端 14 px |
| 照片下方留白 | 高 80 px，從照片下緣延伸至卡片底端 |
| 精準度／星星 | 同一個留白容器，水平、垂直皆置中 |
| 精準度文字 | 棕色 `#AA7756`；數字灰色 `#626262`，等寬數字 |
| 星星 | 每顆 29 px、間隔 12 px |
| 暗星／亮星 | `#B1AB99` → `#FFDB91`，保留未獲得的暗星 |
| 漸亮 | 色彩與陰影以 320 ms ease-in-out 過渡，使用穩定節點，不重新掛載星星 |

留白區以 flex 填滿卡片剩餘高度；不再使用額外的底部 padding 或照片下方 gap 推算位置。
精準度與星星切換時使用相同中心點；重拍提示和過關門檻不影響這個中心點。

## 黃金獵犬星級條件

| 星級 | 條件 |
| --- | --- |
| ★ | 精準度 **> 50%** |
| ★★ | 精準度 **> 60%**，且照片完整包含雙眼判定區 |
| ★★★ | 照片完整包含全身判定區，包括耳朵、腳與尾巴 |

門檻採嚴格大於：50% 不得一星，60% 不得二星。規則由最高星級往下檢查，取符合條件的最高等級。
三星依全身條件判定，沒有另外新增精準度門檻。

精準度保留原本的計算方式：取景框映射到來源圖片後，以「與精準度目標矩形的交集面積／目標面積」
換算百分比，限制在 0～100 並四捨五入。星級的雙眼與全身條件則檢查**實際保存照片的裁切範圍**，
因此相同精準度仍可能得到不同星級。

所有座標均相對於 786 × 1704 來源畫布正規化；雙眼與全身區域涵蓋捷運黃金獵犬的兩張姿勢圖。

| 判定區 | x | y | width | height |
| --- | --- | --- | --- | --- |
| 原有精準度目標 | 0.29 | 0.51 | 0.58 | 0.20 |
| 雙眼 | 0.424 | 0.522 | 0.093 | 0.014 |
| 全身 | 0.268 | 0.486 | 0.52 | 0.268 |

座標定義為 `GOLDEN_RETRIEVER_PHOTO_TARGET`、`GOLDEN_RETRIEVER_PHOTO_EYES`、
`GOLDEN_RETRIEVER_PHOTO_BODY`；全身判定使用包含關係，不以四捨五入後的 100% 代替。

## 動畫與節奏

以下時間以拍立得結果出現為 0 ms，對應 `PHOTO_RESULT_TIMING`。
快門後的結果出現等待沿用原有約 280 ms；若圖片處理較久，則待圖片準備完成。

| 結果時間 | 演出 |
| --- | --- |
| 0～460 ms | 拍立得顯影，精準度初值為 0 |
| 460～1010 ms | 精準度數字跑至實際結果，跑分時間 550 ms |
| 1010～1150 ms | 最終數字停留 140 ms |
| 1150 ms | 有星級時，替換為三顆暗星 |
| 1350 ms | 第一顆開始漸亮，播放第一聲 |
| 1790 ms | 若達二星，第二顆開始漸亮，播放第二聲 |
| 2230 ms | 若達三星，第三顆開始漸亮，播放第三聲 |

星與星間隔 440 ms。最後一顆亮起後保留 640 ms，讓漸亮與鈴聲尾韻收尾，再開放操作：
一星約 1990 ms、二星約 2430 ms、三星約 2870 ms。沒有星級結果時，約 1150 ms 後開放操作。

跑分時間已從最初的 1100 ms 縮短為 550 ms。精準度與星星演出共用同一份時間狀態，
聲音只在新一顆星開始亮起時觸發一次。分頁隱藏時不累加演出時間，每次畫面更新最多累加 64 ms，
避免分頁返回或掉幀後，多顆星與音效擠在同一拍。

重拍、關閉或切換場景時會清除結果動畫並停止本次結果音效。
拍照工作也有世代標記，避免較早的非同步裁切結果在重設後重新出現。

## 星星音效

三個原創合成短鈴聲以 C6 → E6 → G6 上行，第三聲延長尾韻。
每顆星只有一聲，未獲得的暗星不播放音效；已有星級結果時，不再疊加原本的成功提示音。

| 星星 | 音效 ID | 檔案 | 音高 | 長度 |
| --- | --- | --- | --- | --- |
| 第一顆 | `photoStar1` | `public/sounds/game-sfx/photo-star-1.wav` | 1046.50 Hz | 0.34 s |
| 第二顆 | `photoStar2` | `public/sounds/game-sfx/photo-star-2.wav` | 1318.51 Hz | 0.36 s |
| 第三顆 | `photoStar3` | `public/sounds/game-sfx/photo-star-3.wav` | 1567.98 Hz | 0.60 s |

音效格式為 44.1 kHz、單聲道、16-bit PCM WAV。三聲使用相同音量係數 0.48，
播放前預載，透過 `playGameSfx` 沿用全域音量、靜音及開發側欄播放紀錄。
零星失敗與尚未設定星級的關卡，仍使用既有成功／失敗提示音。

重建音效：

```bash
python3 scripts/generate_photo_star_sfx.py
```

## 接入與資料保存

黃金獵犬的三個入口共用 `GOLDEN_RETRIEVER_PHOTO_STARS`：

- `GameSceneView.tsx`：正式版 `scene-85`。
- `MetroFirstSunbeastDogEventModal.tsx`：捷運黃金獵犬事件。
- `ExhibitionExperienceView.tsx`：展覽版 `metro-dog` 拍照階段。

`EventPhotoCaptureLayer` 新增選填的 `starCriteria: PhotoStarCriteria`。
有設定時，一星以上即過關，取代舊的 `passScore` 判定；未設定時，保留各關原本的數值門檻。
其他共用拍照元件的關卡已套用跑分與結果排版，**尚未設定新的星級條件**。
之後可透過三筆 `PhotoStarRule` 各自設定 `scoreAbove` 與 `requiredRegions`；區域座標必須對應實際來源圖片。

`PhotoCaptureResult` 與保存用的 `PhotoCaptureSnapshot` 新增選填的 `stars: 0 | 1 | 2 | 3`。
主線與事件入口將星級寫入黃金獵犬照片及小日獸照片紀錄；展覽版透過 `ExhibitionPhoto` 寫入 sessionStorage。
舊照片可沒有 stars；玩家進度正規化時會捨棄無效星級，不影響舊精準度與照片資料。

免費重拍前後的結果各自保留百分比與星級；選片畫面顯示兩者，收下哪張就保存哪張的結果。
原有以精準度計算的獎勵邏輯維持既有規則，未改用星級換算。
專用預告錄影頁 `SunbeastTrailerStudio` 有自己的時間軸，不屬於這次遊玩結果調整。
