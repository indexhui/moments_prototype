# 展覽改善版變更紀錄

本文件持續記錄「展覽改善版」相對於「東京電玩展版本」的改動。展覽預設入口為 `/game/exhibition`；東京電玩展比較入口為 `/game/exhibition/tgs`。

## 2026-09-25｜01 黃金獵犬日記拼圖改為 2×2

- **範圍**：黃金獵犬日記第一篇的粗糙稿拼圖，以及進入拼圖時顯示的教學動畫。
- **改動前**：四片從左至右排列的直條拼圖，只依水平位置交換。
- **改動後**：四片排成兩欄、兩列；每片顯示原圖對應的四分之一。可拖曳到上、下、左、右位置交換，也可依序點選兩片交換。教學動畫同步顯示 2×2 排列。
- **完成條件**：四片依原圖位置排好後，沿用原有的日記文字與插圖恢復流程，最後顯示「繼續」。
- **版本界線**：只在展覽改善版啟用。東京電玩展版本保留四片直條拼圖與原教學動畫。
- **實作位置**：`src/components/game/DiaryOverlay.tsx`、`src/components/game/ExhibitionExperienceView.tsx`。
- **驗證**：`npm run build` 通過；兩個展覽入口的本機 HTTP 回應皆為 200；`git diff --check` 通過。瀏覽器互動工具本次無法啟動，拖曳與拼圖完成畫面仍需實機檢查。
- **後續補驗**：第 02 項調整時已使用本機 Chrome 驗證 2×2 上下、左右、跨格拖曳及點選交換，皆可完成拼圖並接續劇情。

## 2026-09-25｜02 先完成拼圖，再演出復原文字

- **範圍**：先在展覽改善版的黃金獵犬第一篇日記試行。
- **原因**：跟著拼圖片移動的文字格會分散注意力，固定格子也限制正文的字級與換行。
- **拼圖期間**：只顯示 2×2 插圖拼圖；不顯示文字格、打散文字或空白字格。
- **完成後演出**：拼圖歸位 → 插圖恢復上色、小白淡入 → 完整日記正文逐段浮現，文字由青綠色沉澱為深色 → 出現「繼續」。
- **演出時間**：拼圖完成約 2.2 秒後開始浮現正文；每段演出 620 毫秒，段落間隔 220 毫秒；三段正文完成後約 3.44 秒開放繼續。
- **閱讀排版**：中、英、日文正文統一使用 16px 字級、自然換行，不再把每個字塞進拼圖格；矮螢幕可在書頁內容區捲動閱讀。
- **本次試行方案**：先採用自動復原文字的演出。拼圖後追加一個關鍵小步驟的方案保留為後續比較方向。
- **版本界線**：東京電玩展版本保留直條拼圖與原文字格互動；其他篇章尚未套用此試行。
- **驗證**：`npm run build`、`git diff --check` 通過。本機 Chrome 實際測試展覽改善版的中、英、日文，確認拼圖前無文字格與正文、拼圖後先恢復插圖再逐段浮現全文、三段文字演出結束後才顯示繼續，並能接到後續劇情。393×852 畫面文字完整呈現；320×568 英文畫面可捲動閱讀且沒有水平溢出。東京電玩展版本的直條拼圖、文字格及完成後繼續流程也通過比較驗證。
