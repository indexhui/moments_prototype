# 展覽改善版變更紀錄

本文件持續記錄「展覽改善版」相對於「東京電玩展版本」的改動。展覽預設入口為 `/game/exhibition`；東京電玩展比較入口為 `/game/exhibition/tgs`。

## 文件用途與 Unity／Steam 移植原則

- 本文件記錄玩家體驗、演出順序、試玩回饋與驗收重點，供後續 Unity 製作 Steam 版時參考。網頁程式碼是目前可試玩的原型實作。
- 正式版可依效果採用遊戲引擎的動畫系統、文字幾何、粒子或 shader；技術選擇以畫面品質、效能與維護性決定。網頁的 DOM、CSS、Web Animations API 及像素數值無須逐項移植。
- 文中秒數為目前試玩節奏的參考；字級與版面需依正式版的目標解析度及操作方式調整。各語言先完成可讀的正文排版，再由排版結果決定字片落點。
- 後續紀錄持續區分「要保留的體驗」與「當前網頁做法」，讓引擎端有空間發揮適合的表現方式。

### 本次日記復原的引擎製作參考

| 演出 | 要保留的體驗 | Unity 端可採用的處理方向 |
| --- | --- | --- |
| 2×2 拼圖 | 拿起、落點、交換與正確接縫消失都有回饋；完成後圖片上移 | 由互動狀態驅動位置、縮放及接縫透明度動畫 |
| 字片散出與歸位 | 拼圖期間專注插圖；完成後文字明顯飛散，再依閱讀順序回到文章 | 依文字排版產生字／詞片的目標位置，以引擎動畫曲線控制飛行、旋轉與落定 |
| 紙片退場 | 格框在落定前淡去，文字輕輕落下，收成乾淨正文 | 紙片與文字分層；可用材質透明度、遮罩或 shader 控制紙片消融與字色收斂 |
| 書寫線與短光 | 暖色細線沿字行掃過、逐行退場；光效保持細緻，不遮住字形 | 可用引擎繪線、遮罩、shader 或少量粒子呈現；由同一條演出時間軸協調 |
| 完成與閱讀 | 全文可讀、沒有殘留格框；文字復原完成後才開放繼續 | 由演出完成事件切換閱讀狀態；提供減少動態的簡化演出 |

以上為移植方向，尚未實作或驗證 Unity／Steam 版本。現階段先保留第 05 項的試玩結果。

## 2026-09-25｜01 黃金獵犬日記拼圖改為 2×2

- **範圍**：黃金獵犬日記第一篇的粗糙稿拼圖，以及進入拼圖時顯示的教學動畫。
- **改動前**：四片從左至右排列的直條拼圖，只依水平位置交換。
- **改動後**：四片排成兩欄、兩列；每片顯示原圖對應的四分之一。可拖曳到上、下、左、右位置交換，也可依序點選兩片交換。教學動畫同步顯示 2×2 排列。
- **完成條件**：四片依原圖位置排好後，沿用原有的日記文字與插圖恢復流程，最後顯示「繼續」。
- **版本界線**：只在展覽改善版啟用。東京電玩展版本保留四片直條拼圖與原教學動畫。
- **實作位置**：`src/components/game/DiaryOverlay.tsx`、`src/components/game/ExhibitionExperienceView.tsx`。
- **驗證**：`npm run build` 通過；兩個展覽入口的本機 HTTP 回應皆為 200；`git diff --check` 通過。瀏覽器互動工具本次無法啟動，拖曳與拼圖完成畫面仍需實機檢查。
- **後續補驗**：第 02 項調整時已使用本機 Chrome 驗證 2×2 上下、左右、跨格拖曳及點選交換，皆可完成拼圖並接續劇情。

## 2026-09-25｜02 先完成拼圖，再演出復原文字

- **範圍**：先在展覽改善版的黃金獵犬第一篇日記試行。
- **原因**：跟著拼圖片移動的文字格會分散注意力，固定格子也限制正文的字級與換行。
- **拼圖期間**：只顯示 2×2 插圖拼圖；不顯示文字格、打散文字或空白字格。
- **完成後演出**：拼圖歸位 → 插圖恢復上色、小白淡入 → 完整日記正文逐段浮現，文字由青綠色沉澱為深色 → 出現「繼續」。
- **演出時間**：拼圖完成約 2.2 秒後開始浮現正文；每段演出 620 毫秒，段落間隔 220 毫秒；三段正文完成後約 3.44 秒開放繼續。
- **閱讀排版**：中、英、日文正文統一使用 16px 字級、自然換行，不再把每個字塞進拼圖格；矮螢幕可在書頁內容區捲動閱讀。
- **本次試行方案**：先採用自動復原文字的演出。拼圖後追加一個關鍵小步驟的方案保留為後續比較方向。
- **版本界線**：東京電玩展版本保留直條拼圖與原文字格互動；其他篇章尚未套用此試行。
- **驗證**：`npm run build`、`git diff --check` 通過。本機 Chrome 實際測試展覽改善版的中、英、日文，確認拼圖前無文字格與正文、拼圖後先恢復插圖再逐段浮現全文、三段文字演出結束後才顯示繼續，並能接到後續劇情。393×852 畫面文字完整呈現；320×568 英文畫面可捲動閱讀且沒有水平溢出。東京電玩展版本的直條拼圖、文字格及完成後繼續流程也通過比較驗證。

## 2026-09-25｜03 拼圖置中與歸位回饋

- **範圍**：展覽改善版的黃金獵犬第一篇日記，保留 2×2 拖曳／點選交換規則。
- **空間運用**：拼圖與一句操作提示在書頁內容區置中；最後一片歸位後，先短暫收合整張圖片，再平順上移到正文上方，將下半頁交給文字演出。置中位置依畫面可用高度計算。
- **操作回饋**：拿起的拼片浮起、帶有陰影；移到另一格時顯示淡綠落點。放到拼圖外會回到原位。相鄰兩片都回到正確位置後，接縫逐漸淡去。
- **完成節奏**：歸位收合約 680 毫秒；720 毫秒後開始上移，上移約 900 毫秒。沿用插圖上色與小白淡入，約 2.2 秒後接續文字。
- **試玩修正**：曾試行墨色帶出正文，但回饋是演出差異不夠明顯；已由第 04 項的字片重組演出替換。先前被否決的散片托盤與按住蓋章方案已撤回。
- **實作位置**：`src/components/game/DiaryOverlay.tsx`。
- **驗證**：本機 Chrome 驗證置中、拖曳浮起與落點提示、上下交換、拖出拼圖返回原位、正確相鄰片接縫消失，以及完成後圖片上移。

## 2026-09-25｜04 字片飛回文章

- **範圍**：展覽改善版的黃金獵犬第一篇日記，拼圖完成後自動播放。
- **演出**：文字從插圖下半部飛散成帶紙色格框的字片 → 字片短暫漂浮、排列成打散的文字格 → 依閱讀順序飛回段落位置，歸位時微彈並亮起 → 格框逐漸消融，留下完整文章。
- **節奏**：拼圖完成約 2.2 秒後開始；字片演出約 3.6 秒，最後才顯示「繼續」。完成狀態由文字演出通知，避免按鈕提早出現。
- **排版**：先量測正常文章的字詞位置，再讓字片飛回這些位置；中、日文以字片呈現，英文以詞片呈現。正文保持 16px 與自然換行，完整保留三段日記。
- **小螢幕**：字片散開範圍依可用空間縮放；下方不足時自動把文字帶進視野一次，之後仍可自由捲動閱讀。完成後移除字片層的顯示，避免透明格框造成水平溢出。
- **減少動態**：系統開啟「減少動態效果」時，以短淡入直接呈現全文。
- **技術**：使用瀏覽器 Web Animations API，未新增套件；尺寸或字型載入改變時重算落點，保留演出進度。
- **實作位置**：`src/components/game/ExhibitionDiaryTextReconstruction.tsx`、`src/components/game/DiaryOverlay.tsx`。
- **驗證**：`npm run build`、`git diff --check` 通過。本機 Chrome 實際完成展覽改善版的中、日文 393×852，以及英文 320×568：確認拼圖前沒有文字干擾、字片確實位移並歸位、三段全文保持 16px、完成後無水平溢出、小螢幕可捲到最後一段，且能接續劇情。減少動態模式通過；以上流程無瀏覽器執行錯誤。本輪不進行東京電玩展版本比較。

## 2026-09-25｜05 細緻化文字歸位的倒數第二拍

- **回饋**：字片重組的方向保留，改善歸位後、收成正文前的畫面質感。
- **格框交接**：紙片在接近文章位置時就開始淡去，落定前退場，避免字框擠成連續格線。移除歸位後的綠色底框與外擴光暈。
- **落定節奏**：歸位波次由約 0.58 秒拉開為約 0.86 秒；字片從略高於字行的位置輕輕落下，取代原先 12% 的放大彈跳。整體文字演出仍約 3.6 秒。
- **書寫線**：依實際換行位置量測字行，出現細淡的暖色書寫線與一道短光，隨文字歸位由左往右掠過，再逐行淡出；完整正文保留乾淨紙面。
- **紙片質感**：改成米白紙色漸層、較淡的邊框與陰影，字色從暖褐收成正文深色。
- **實作位置**：`src/components/game/ExhibitionDiaryTextReconstruction.tsx`。
- **驗證**：`npm run build`、`git diff --check` 通過。Chrome 實際測試中文 393×852、英文 320×568，檢視歸位與落定畫面，確認最終交接前各字片格框已退場、三段全文保留 16px、無水平溢出、可捲至最後一段並接續劇情；重新載入後兩條流程皆無瀏覽器執行錯誤。

## 2026-09-25｜06 第一次進公司過場縮短、同事接話提早

- **範圍**：展覽改善版第一次抵達公司的 `office-opening → work-arrival`。
- **回饋**：小麥打字過場偏長，回頭後接同事對話有明顯停頓。
- **時間調整**：公司地點介紹維持約 1.65 秒；小麥打字由約 1.7 秒縮為 1 秒（1000 毫秒）；抬頭後停留 0.45 秒再接同事對話。過場時間由約 4.62 秒縮為 3.1 秒。曾試行 0.18 秒的抬頭停留，因動作太一閃而過，依試玩回饋拉長。
- **對話銜接**：進公司時就預載同事立繪；第一句同事對話開始時直接出字，省去原有 90 毫秒的額外起始等待。短過場自動銜接，不再閃現「點一下繼續」提示。
- **引擎製作意圖**：以一個短打字循環交代小麥正在工作，短暫停留讓抬頭動作看得清楚，再接同事開口。Unity 可用同一演出時間軸串起動作與對話啟動事件，並提前準備同事立繪；本文時間為試玩參考。
- **實作位置**：`src/components/game/ExhibitionExperienceView.tsx`。
- **驗證**：前一輪 `npm run build` 與 Chrome 流程驗證通過：同事立繪與對話同時就緒、約 32 毫秒內開始出字，可完成對話並進入資料箱遊戲，無瀏覽器執行錯誤。後續依回饋將打字段調為 1000 毫秒、抬頭停留調為 450 毫秒；時間常數微調後 `git diff --check` 通過。
