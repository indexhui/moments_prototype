# 展覽版體驗流程：直太郎 → 青蛙

## 企劃判斷

這一版不是單一五分鐘事件，而是一條「一天半」的完整垂直切片：直太郎讓殘缺日記首次恢復後，小麥理解「找回小日獸＝恢復日記」的目標並完整回看前天的爭執；工作與居家行動再建立生活感，最後由青蛙事件建立下一隻小日獸的追蹤節奏。

完整遊玩預估約 8–12 分鐘。若現場仍需嚴格控制在 5 分鐘，建議導覽模式只保留：捷運漫畫與拍照、缺一格日記、枕頭尋片、日記恢復、甜點店青蛙拍照、爭吵倒敘；紙箱、路線、傳單與工作值遊戲改成可選或工作人員一鍵略過。

## 因果鏈

1. 直太郎被拍下後，小貝狗先說明小日獸是從小白交換日記裡逃出的日記片段；此時不提前顯示現在時間的日記。
2. 這個說明讓小麥先回想起爭執、小白沉睡與發光日記的異狀。
3. 回憶完整結束後，小貝狗才提醒日記出現；直太郎影像飛入日記，玩家再把現有片段排正並確認缺口是實體缺片。
4. 日記文字恢復後，小麥確認「拍下小日獸＝恢復日記」；接著由捷運到站聲拉回行程，上班讓缺片尋找被迫延後。
5. 小麥繼續工作到黃昏，下班途中不再重播回憶，直接回家；掃地則是「一邊做原本該做的家務、一邊尋物」。
6. 找到缺片後先由玩家打開日記，再讓缺片自動回到直太郎殘頁；正文前、後兩段各占一個手機頁面，不用垂直捲動把兩組字格塞在同一頁。
7. 捷運篇完成後先讓小麥讀完並確認「找回小日獸會恢復日記」的先前推測，再跑去房間確認；小白仍未恢復，不能直接跳成已經好轉。
8. 小貝狗提醒拿出日記後，才讓一格光從日記飛進小白；確認小白仍未醒後，小貝狗再提醒「下一篇日記」，玩家重新開書、從目錄點入青蛙殘篇並先完成紙膠帶頁，才得到「街道」線索。小麥決定明天前往街道、今天先休息；隔天早上出門後才進入路線規劃。
9. 街道、便利商店與甜點店各有一次完整拍照與日記更新；三張照片依序把青蛙篇補齊，甜點店才正式收服青蛙。
10. 回家後不再開啟下一章主線，改以 Demo 完成頁回顧玩家拍到的小日獸與完成的小遊戲，並引導至官方網站。

## 新工作值玩法

- AI 會在電腦桌面產出四種擬人小居民：完成檔案小郵差、錯字蟲、兩層彈窗怪與三格當機雲；角色會自行選擇目的地、平滑轉向、偶爾停頓，彼此碰撞時會分開。
- 玩家不需切換工具：點擊完成檔案即送出；快速劃過錯字蟲、彈窗怪與當機雲即處理。食指與手刀會追到實際操作位置，劃切期間同步顯示手指軌跡。
- 錯字蟲一劃即完成；彈窗怪需劃兩次、當機雲需劃三次。未完成的角色會顯示剩餘耐久並受擊逃跑，讓重複命中有清楚回饋。
- 每次正確互動會掉出角色配色的方形像素碎片；最後一擊使用較大範圍的瓦解效果，未結束的多層角色則留下裂痕。
- 三個累積目標為 30、60、90；每完成一輪暫停並選擇精準指尖、AI 副手或俐落手勢。
- 玩法借用 active-incremental 的「主動操作 → 累積 → 升級 → 更快產出」節奏與追擊動感，不使用參考作品的小豬、鐵鎚、美術或付帳敘事。

## 辦公遊戲方案 2：Todo List

- 核心循環為「選一張待辦 → 沿蛇形引導線左右刷 → 填滿工作格 → 打勾結案 → 累積效率 → 選擇流程升級」。數字成長直接綁在玩家完成的任務上，不再使用抽象工作值核心。
- 待辦箱最多同時容納四張任務，新任務會持續進箱；每張都有期限，歸零後標記逾期並提高待辦壓力，但不會立即讓展覽玩家失敗。
- 任務包含回覆客戶郵件、校對簡報、整理共享資料夾與填寫週報，分別有不同工量、期限與效率獎勵。
- 四類便利貼都使用順暢的左右蛇形手勢，但引導線的彎曲、密度與往返次數不同。玩家可維持按壓，向左或向右完成一段、再反向時各填一格，不需放開重按；實際觸點會帶著淡出筆尾、流動亮線、筆頭與碎光，清楚對應玩家手勢。
- 任務填滿後不直接消失：先顯示完成勾、整張紅線劃除與「ITEM 完成」章，再滑入封存區。這借用工作管理軟體「完成後仍短暫保留、再封存」的資訊層級。
- 35、75 效率時只提供主動型改善：手勢捷徑、工作範本或優先標籤；最終達到 120 效率完成本輪，不加入自動處理。
- 方案 1 與方案 2 繼續保留於展覽右側快捷入口，方便和方案 3 的直接配貨裝箱節奏比較。

## 辦公遊戲方案 3：資料裝箱

- 核心循環為「看三張交付單 → 從桌面拿物件 → 拖進正確資料箱 → 清單逐項打勾 → 封箱送出 → 新單補位」。目標是寄出 5 箱，不設抽象升級中斷配貨節奏。
- 同時呈現三個開箱，讓玩家在有限桌面中掃視需求並規劃下一件要拿什麼；補給區的六類物件可重複拿取，符合辦公資料可複製、但每箱清單只能勾一次的題材。
- 手機上使用 Pointer Events 跟手拖曳；也保留「先點物件、再點箱子」與鍵盤操作。錯箱會搖動並說明該箱不需要什麼，正確入箱會直接出現在填充紙上。
- 方案借用參考圖的俯視工作台、打開的箱子、夾在箱旁的訂單、桌面散物與完成後送走補位，不重用參考作品的商品、貨幣、商店敘事或美術。
- 方案 1、方案 2、方案 3 都保留在展覽右側快捷入口，網址可用 `?preview=work-value`、`?preview=work-todo`、`?preview=work-pack` 直接比較。

## 辦公遊戲方案 4：社群畫布

- 四篇行銷需求依序為新品麵包、午後甜點、生日蛋糕與人氣感謝；每篇都有獨立受眾、加分主題和素材預算。
- 玩家從素材庫購買貼紙並放上 1080×1080 模擬貼文；畫布上的貼紙支援跟手拖曳，選取後可旋轉、循環縮放或刪除並退回預算。
- 發佈人氣由貼紙本身吸引力、需求主題命中數、畫面使用的象限數與剩餘預算共同計算，讓「多放昂貴素材」與「節省預算」之間保留取捨。
- 初始提供可頌、咖啡、星光與吊牌。累積人氣後依序解鎖愛心、長棍麵包、蛋糕、花朵、吐司、攪拌器、隔熱手套與青蛙店長；解鎖素材會直接進入下一篇可用的素材庫。
- 手繪貼紙沿用參考圖的奶油白外框、珊瑚紅／森林綠線稿語言，以專案自有素材表呈現，不重用參考圖中的原始圖像。
- 方案 4 保留在展覽右側快捷入口，也可用 `?preview=work-social` 直接進入。

## 辦公遊戲方案 5：智慧資料夾養成

- 畫面直接以參考圖的視覺關係發想：上方是桌面資料夾捷徑，中央是黑色大資料夾，已收入的白色文件從袋口露出；資料夾正面保留名稱、季度與 Files 數字，右下角是可操作的藍色星光整理鍵。
- 文件卡沿用參考圖的資訊層級，每張具有英文標題、短備註、三行內容、表情符號與 Files 數字。玩家先選 Layout、AI、Daily 或 Social 資料夾，再點擊下方文件收入目前資料夾；選錯時文件不消失，大資料夾會搖動並提示正確關係。
- 每個資料夾裝入三份同類文件後，藍色星光才會亮起。玩家按下後三張紙往袋內縮合，轉成一個乾淨資料包；本次三張卡的 Files 總和會加入資料夾，並乘上目前資料夾等級計算整理分。
- 各分類資料夾每完成兩個資料包提升一級。總計完成 2 包解鎖彩色文件標籤、4 包解鎖建議資料夾、6 包解鎖第三份文件進入後自動觸發星光整理，讓實際操作隨進度逐步加速。
- 完成 8 個資料包後結算。方案 5 可由展覽快捷入口或 `?preview=work-files` 直接進入。

## 辦公遊戲方案 6：自動化資料工廠

- 畫面以參考圖的等距視角機器與輸送帶為視覺核心，但不重用品牌、網站版面或原機器造型。工作流不再是一張要答對的節點圖，而是一條持續運轉的實體資料產線。
- 資料包由左側進站：藍色普通件要撥到 LEFT、橘色急件要撥到 RIGHT；紅色壞資料需在通過機器前直接拍擊修復，紫色靈感包拍中後可讓本次產值加倍。玩家必須在分流、搶加倍與機器溫度之間快速切換注意力。
- 每次正確出貨提升 Combo 與產值；分錯出口或漏掉壞資料會造成堵塞並快速升溫。溫度到達上限時輸送帶停機，玩家需按 COOL 把溫度降到安全範圍，沒有失敗結束或重頭再來。
- 增量感來自「把自己的操作交給機器」：完成 6 件解鎖自動分流器，14 件解鎖錯誤清洗器，22 件解鎖智慧散熱器。每次安裝模組後，舊工作自動化，同時把注意力讓給靈感加倍與更高流量。
- 完成 30 件出貨後結算總產值、最長 Combo 與堵塞次數。方案 6 可由 `?preview=work-flow` 直接進入。

## 辦公遊戲方案 7：素材合成工作室

- UI 依照參考草圖重排：最上方左側是大型人氣數字，右側是升級入口；第二層白色卡片把藍色 PO 文資料夾、依該篇配方數量生成的素材需求格與 SEND 放在一起；畫面下方才是 WORK 按鈕與橫向 ENERGY 體力條。第一篇只需要一張相片，因此只出現唯一一個需求格。
- WORK 按鈕不再直接產生素材。初始每次按壓增加 20 體力，體力達到 100 才生成一個立體 App 圖示並把體力歸零；素材依類型累積數量，即使已有素材等待使用或正在飛行，玩家仍可繼續 WORK 生產下一個。
- 玩家點擊素材庫中符合目前配方的圖示後，該素材會先從按鈕上方升起，再沿弧線飛往上方資料夾需求格；720ms 動畫完成後才真正填入格子。填入後，需求格與左側資料夾都直接顯示實際素材 App 圖示，不用勾選符號代替。資料夾條件完成時，同面板的 SEND 由灰色解鎖為紅色，發佈後以愛心人氣作為主要收益。
- 技能樹入口在第一篇發佈前保持灰色鎖定。解鎖後打開深色科技盤，可消耗人氣點亮三條分支：AI CLICK 會自動按下 WORK 並逐級縮短間隔；RARE FILE 提升稀有素材機率，稀有素材帶金色星級且完成貼文時增加隱藏愛心收益；SUPPORT 提升應援品出現率，咖啡、珍奶與提神飲料會帶翅膀飛入工作區，點擊後提供限次體力倍率與爆擊率。
- 六篇配方依序需要 1、1、2、2、2、2 個素材，全部 SEND 後完成本季人氣 KPI。方案 7 可由 `?preview=work-clicker` 直接進入。
