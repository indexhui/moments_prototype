# 展覽版體驗流程：直太郎 → 青蛙

## 企劃判斷

這一版不是單一五分鐘事件，而是一條「一天半」的完整垂直切片：直太郎讓殘缺日記首次恢復後，小麥理解「找回小日獸＝恢復日記」的目標並完整回看前天的爭執；工作與居家行動再建立生活感，最後由青蛙事件建立下一隻小日獸的追蹤節奏。

完整遊玩預估約 8–12 分鐘。若現場仍需嚴格控制在 5 分鐘，建議導覽模式只保留：捷運漫畫與拍照、日記初次恢復、回家確認小白、甜點店青蛙拍照、爭吵倒敘；紙箱、路線、傳單與工作值遊戲改成可選或工作人員一鍵略過。

## 因果鏈

1. 直太郎被拍下後，小貝狗先說明小日獸是從小白交換日記裡逃出的日記片段；此時不提前顯示現在時間的日記。
2. 這個說明讓小麥先回想起爭執、小白沉睡與發光日記的異狀。
3. 回憶完整結束後，小貝狗才提醒日記出現；直太郎影像飛入日記，玩家把現有片段排正，確認日記開始恢復、但仍有許多空白內容。
4. 日記文字恢復後，小麥確認「拍下小日獸＝恢復日記」；接著由捷運到站聲拉回行程，先去公司上班。
5. 小麥繼續工作到黃昏，下班途中不再重播回憶，直接回家確認小白的狀況；展覽主路徑不再進入掃地機器人或客廳尋物。
6. 回到家後，小麥因為已經收集到黃金獵犬，立刻猜測小白可能恢復了，從客廳直接前往小白房間。
7. 進房後小白仍未恢復，不能直接跳成已經好轉；小貝狗提醒拿出日記，黃金獵犬那一格的光才開始進入小白。
8. 小貝狗提醒拿出日記後，才讓一格光從日記飛進小白；確認小白仍未醒後，小貝狗再提醒「下一篇日記」，玩家重新開書、從目錄點入青蛙殘篇並先完成紙膠帶頁，才得到「街道」線索。完成後不再用第三人稱旁白替小麥做決定，直接進入「第一天結束／休息」，隔天由玩家關掉小麥的鬧鐘，再從家門口進入路線規劃。
9. 隔日路線板沿用主線雙格慣例，右側保留日記入口，路線卡僅使用原始地點圖示。只要路線含街道就接展覽主線；若兩格都沒有街道，先播出發與工作快轉，再由小麥總結沒有遇到小日獸、小貝狗提醒重看日記，回到已開啟日記的路線板。

## 新工作值玩法

- AI 會在電腦桌面產出四種擬人小居民：完成檔案小郵差、錯字蟲、兩層彈窗怪與三格當機雲；角色會自行選擇目的地、平滑轉向、偶爾停頓，彼此碰撞時會分開。
- 玩家不需切換工具：點擊完成檔案即送出；快速劃過錯字蟲、彈窗怪與當機雲即處理。食指與手刀會追到實際操作位置，劃切期間同步顯示手指軌跡。
- 錯字蟲一劃即完成；彈窗怪需劃兩次、當機雲需劃三次。未完成的角色會顯示剩餘耐久並受擊逃跑，讓重複命中有清楚回饋。
- 每次正確互動會掉出角色配色的方形像素碎片；最後一擊使用較大範圍的瓦解效果，未結束的多層角色則留下裂痕。
- 三個累積目標為 30、60、90；每完成一輪暫停並選擇精準指尖、AI 副手或俐落手勢。
- 玩法借用 active-incremental 的「主動操作 → 累積 → 升級 → 更快產出」節奏與追擊動感，不使用參考作品的小豬、鐵鎚、美術或付帳敘事。

## 辦公遊戲方案 2：Todo List

- 核心循環為「選一張待辦 → 沿蛇形引導線左右刷 → 填滿工作格 → 打勾結案 → 累積效率 → 選擇流程升級」。數字成長直接綁在玩家完成的任務上，不再使用抽象工作值核心。
- 待辦箱最多同時容納四張任務，新任務會持續進箱；每張都有期限，歸零後標記逾期並提高待辦壓力，但不會立即讓展覽玩家失敗。
- 任務包含回覆客戶郵件、校對簡報、整理共享資料夾與填寫週報，分別有不同工量、期限與效率獎勵。
- 四類便利貼都使用順暢的左右蛇形手勢，但引導線的彎曲、密度與往返次數不同。玩家可維持按壓，向左或向右完成一段、再反向時各填一格，不需放開重按；實際觸點會帶著淡出筆尾、流動亮線、筆頭與碎光，清楚對應玩家手勢。
- 任務填滿後不直接消失：先顯示完成勾、整張紅線劃除與「ITEM 完成」章，再滑入封存區。這借用工作管理軟體「完成後仍短暫保留、再封存」的資訊層級。
- 35、75 效率時只提供主動型改善：手勢捷徑、工作範本或優先標籤；最終達到 120 效率完成本輪，不加入自動處理。
- 方案 1 與方案 2 繼續保留於展覽右側快捷入口，方便和方案 3 的直接配貨裝箱節奏比較。

- UI 依照參考草圖重排：最上方左側是大型人氣數字，右側是升級入口；第二層白色卡片把藍色 PO 文資料夾、依該篇配方數量生成的素材需求格與 SEND 放在一起；畫面下方才是 WORK 按鈕與橫向 ENERGY 體力條。第一篇只需要一張相片，因此只出現唯一一個需求格。
- WORK 按鈕不再直接產生素材。初始每次按壓增加 20 體力，體力達到 100 才生成一個立體 App 圖示並把體力歸零；素材依類型累積數量，即使已有素材等待使用或正在飛行，玩家仍可繼續 WORK 生產下一個。
- 玩家點擊素材庫中符合目前配方的圖示後，該素材會先從按鈕上方升起，再沿弧線飛往上方資料夾需求格；720ms 動畫完成後才真正填入格子。填入後，需求格與左側資料夾都直接顯示實際素材 App 圖示，不用勾選符號代替。資料夾條件完成時，同面板的 SEND 由灰色解鎖為紅色，發佈後以愛心人氣作為主要收益。
- 技能樹入口在第一篇發佈前保持灰色鎖定。解鎖後打開深色科技盤，可消耗人氣點亮三條分支：AI CLICK 會自動按下 WORK 並逐級縮短間隔；RARE FILE 提升稀有素材機率，稀有素材帶金色星級且完成貼文時增加隱藏愛心收益；SUPPORT 提升應援品出現率，咖啡、珍奶與提神飲料會帶翅膀飛入工作區，點擊後提供限次體力倍率與爆擊率。
- 六篇配方依序需要 1、1、2、2、2、2 個素材，全部 SEND 後完成本季人氣 KPI。方案 7 可由 `?preview=work-clicker` 直接進入。

## 展覽頁

- 路徑：`/game/exhibition`
- 正常遊玩時，網址的 `preview` 會隨目前 phase 更新；敘事台詞與直太郎拍照段落另以 `sceneStep` 記錄幕次。展覽頁會在第一個畫面掛載前解析這兩個參數，因此重新整理會直接從對應 scene 開始，不會先播放開場。
- 可用 `?preview=<phase>` 從指定段落驗收，例如：
  - `?preview=metro-comic`
  - `?preview=diary-incomplete`
  - `?preview=argument-flashback`（小日獸說明後的爭吵、小白沉睡與異狀回憶）

  - `?preview=post-puzzle-metro`（確認捕捉小日獸會恢復日記）
  - `?preview=post-flashback-metro`（日記段落結束、回到捷運到站）
  - `?preview=office-opening`
  - `?preview=work-dusk`
  - `?preview=home-search`（收集黃金獵犬後直接回家確認小白）
  - `?preview=diary-restore`（獨立驗收入口，不在正常展覽路徑）；加上 `&sceneStep=restoration` 可直接驗收補圖與分段正文
  - `?preview=frog-diary-fragment`（封面）；加上 `&sceneStep=catalog` 可直接驗收目錄與青蛙殘篇入口
