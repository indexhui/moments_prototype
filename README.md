# moment_prototype

`moment_prototype` 是一個以手機直式畫面為核心的模擬遊戲原型。玩家會先進入「安排路線」拼圖階段，再進入劇情場景、事件、上班過場、下班獎勵，之後循環進入下一輪路線安排。

## Current Scope

- 首頁與手機畫布入口
- 安排路線拼圖：拖放、召回、連通驗證、錯誤回滾
- 劇情場景：資料驅動場景、章節內回顧 modal
- 事件演出：捷運座位、街道路線事件、背景特效、表情與頭像金手指
- 玩家進度：`localStorage` 持久化、下班獎勵、解鎖條件
- 桌面開發殼層：左右側欄顯示進程、玩家狀態與事件金手指

## Main Routes

- `/`：首頁
- `/game/arrange-route`：安排路線階段
- `/game`：第一個劇情場景
- `/game/[sceneId]`：動態劇情場景
- `/game/exhibition`：展覽改善版（預設展覽入口）
- `/game/exhibition/tgs`：東京電玩展版本，用於與展覽改善版比較
- `/muffin-knight`：小日獸・點心大作戰，四座競技場、七種角色能力與動作圖。森林彈簧、屋頂傳送門、月光移動平台；第一關固定低難度（不強化、不加速、最多 3 隻怪）。第四關「星火遺跡」為 2160 寬的捲動場景，穿越入口、水道、機關庭，寬固定平台、兩座高岩壁和低岩階混合配置，三座繩索升降台載人、怪物與漢堡上下移動；探索視野約 1477 寬、魔王戰約 1714 寬，低動態模式也保留廣角；四次三選一學習小日獸專屬招式，選到的角色權重由 1 提高至 10 起，允許已升級角色連續出場，連續兩次未抽中後保底回到已升級角色。浣熊吸牆、蹬牆蓄勢，第三次升級解鎖全角色殘影接力與專屬接招。關主「負星岩衛」體型擴為 2.1 倍，依距離、阻路與玩家停留時間選擇追擊、躍擊或落印；1.3 秒預告後能抬高岩階、壓低玩家腳下平台並升起其他木台，地形會實際載動角色、漢堡及封印，隨後回復；封印岩晶使用六格透明素材呈現裂損、爆裂與殘骸，命中飛屑、破裂碎塊旋轉彈跳並搭配分層音效；破除高台封印會降下天橋並解除核心護甲。守衛耐久提升至 72，縮短收招間隔並加快追擊；66% 血量進入崩解，仍在原遺跡戰場。低於 33% 才進入「天階崩升」終局：先預告，再轉為高 2040 的縱向天階，廣角鏡頭追隨玩家上攀，寬平台、兩座升降木台與攀爬岩壁交錯配置。巨像會隨高度上升，三連掌鎖定預告落點、召喚裝甲岩靈；洪潮從玩家下方預警 2 秒後上升。沿途三枚鎖星岩晶每枚回一顆生命，全部打碎解除核心護甲。終局巨像軀幹沒有接觸傷害，封印期間不吸收子彈；掌擊、洪潮與小怪仍會造成傷害。破印中斷待發攻擊、給予 1.5 秒保護與 2.4 秒收招窗口；獵犬 C 優先攻擊附近岩晶並借力反彈。營火存點在落地時點亮，失足回到最近存點。大招後過載 3 秒，反擊傷害 ×2。右側「守衛 III・登塔」直接演練同一終局，前兩階段演練保留原場地。收齊 15 漢堡並擊敗守衛通關。含獨立音效／音樂、右側快速切關及不計紀錄的守衛演練（使用目前角色並配上其專屬升級）。
- `/trial/recording`：預告錄影工具，選擇正式版／展覽版、16:9／手機比例與對話顯示

## Tech Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Chakra UI v3

## Project Structure

- `src/app`：頁面與 metadata
- `src/components/game`：遊戲舞台與互動 UI
- `src/lib/game`：場景、流程、玩家進度、事件定義
- `public`：場景背景、角色素材、音訊與拼圖相關圖片
- `docs/GAME_ROUTE_PROTOTYPE_LOG.md`：目前最可信的功能規格與流程紀錄

## Local Development

```bash
npm run dev
```

開啟 [http://localhost:3000](http://localhost:3000)。

點心大作戰：方向鍵／A、D 移動，空白鍵跳躍，↓／S 穿落腳下薄平台（每次按下只穿一層，岩塊與地面不穿透），J／X 能力，青蛙 C 吞怪／吐彈，浣熊 Shift／L 衝刺；吸牆時空白鍵蹬牆。取得專屬升級後：黃金獵犬空中再按跳躍，二段翻滾前 0.36 秒無敵，隨後俯落；鴕鳥貼近岩壁再按跳躍，長腳跨岩，每次滯空一次；蛇可按住 C 盤身蓄力，放開彈射、方向控制斜飛，滿蓄有短暫無敵，每次滯空一次。獵犬 C 撲擊前方敵人，命中反彈躍高並重置，失手每次滯空限一次；保留原二段翻滾。海豹 C 放置 4 秒浪泡，落踩後彈高、爆泡傷敵並清除震波，每次滯空一顆；海豹同方向連按兩下（←←／→→ 或 A A／D D）沿地面翻滾，前 0.25 秒無敵、冷卻 0.9 秒，撞岩壁停止。第四關第 2 次選卡解鎖蹬牆蓄勢，第 3 次選卡（8 漢堡）解鎖全隊接力：Shift／L 後 0.85 秒內重新按 J 接專屬招式。P／Esc 暫停。選卡在開場及 4／8／12 漢堡發生，戰鬥凍結；每 4 漢堡補一顆生命。每個角色基礎出場權重為 1，每個相關招式 +9；已升級的當前角色保留 70% 權重，可連續出場，未升級的當前角色不連抽。連續兩次未抽中升級角色後保底，長期未出場的已升級角色會優先補入，右側顯示抽選占比。所有招式只在本局生效。守衛躍擊落點先鎖定、預告 0.8–1.1 秒，落地後有反擊窗口，核心暴露時承受 1.5 倍傷害。設計重點是變身接力、招式與地形互相配合。玩法與平台可達性測試：`node --test scripts/muffin-knight.test.cjs`。

## Important Notes

- 玩家進度儲存在 `localStorage`，key 為 `moment:player-progress`
- 上班過場切到下班場景時，避免先卸載過場；應直接跳頁，否則會出現底層頁面閃爍
- 目前 git 歷史已重建，repo 只有一個 baseline 初始化 commit
- 舊網站時期的 SEO 文件仍保留在 `docs/`，但不代表目前遊戲原型的真實結構
