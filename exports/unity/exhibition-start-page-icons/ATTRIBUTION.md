# Icon attribution

The `settings`, `music-on`, `music-off`, `sfx-on`, and `sfx-off` icons include shapes from Font Awesome Free 6, obtained through the project's `react-icons` dependency.

- Font Awesome: <https://fontawesome.com/>
- License: CC BY 4.0, <https://creativecommons.org/licenses/by/4.0/>
- `react-icons`: <https://react-icons.github.io/react-icons/>

The `chapter-reset` source asset is also identified as a Font Awesome-style rotate-back icon in the existing SVG.
